## First release

Tag: `v1.0.0`

Title: `ProveIt v1.0.0 — Evidence before “done”`

Release notes:

```markdown
ProveIt is a portable Agent Skill that requires coding agents to back completion claims with current evidence.

Highlights:

- Quick, Standard, and Strict verification profiles
- VERIFIED, PARTIALLY VERIFIED, FAILED, and BLOCKED status contract
- Portable skill for Codex, Claude Code, and generic Agent Skills
- Native adapters for Cursor and GitHub Copilot
- Bash and PowerShell installers
- Dependency-free evidence recorder with redaction and Markdown reports
- Automated tests and cross-platform CI
```
